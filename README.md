# Saffron Globe News

A premium responsive global-news and magazine website template built with HTML, CSS and vanilla JavaScript.

## Included
- Editorial newspaper-style homepage
- Responsive desktop/tablet/mobile layouts
- World, Security, Diplomacy, Economy and Analysis sections
- Long-form article template
- Functional client-side story search
- World in Video section with official embeds
- Newsletter demo interaction
- Accessible navigation and keyboard search shortcut (/)
- Favicon and branded visual system
- No framework or build step required

## Quick start
1. Download the repository.
2. Open `index.html` in a browser, or deploy the folder to any static host.
3. Replace the demo stories, images and video embeds with content you are licensed to publish.
4. Update the branding in `saffron-globe-logo.svg`.
5. Connect the newsletter form to your email provider before production.
6. Add your own analytics property if required.

## File structure
- `index.html` — homepage and demo content
- `article.html` — dynamic article presentation
- `style.css` — complete visual system and responsive styles
- `script.js` — navigation, search, newsletter demo and story linking
- `saffron-globe-logo.svg` — logo
- `favicon.svg` — favicon

## Commercial release checklist
Before selling or publishing a finished installation:
- Replace all third-party/demo photographs with assets whose commercial license you have.
- Replace or rewrite demo news copy; do not redistribute copyrighted publisher copy without permission.
- Verify rights for every video embed and external asset.
- Remove any developer/test analytics identifiers.
- Add the buyer's own domain, branding and contact details.
- Connect production newsletter and analytics services.
- Test all links and article pages after customization.
